# Prominence — квесты на русском

Русский перевод всех 31 файла глав из предоставленного архива `chapters.rar`. Переведены явно заданные названия глав и заданий, описания, подзаголовки, названия целей и всплывающие подсказки.

## Установка

1. Полностью закройте Minecraft. Если играете на сервере, остановите сервер.
2. Откройте папку своей сборки и найдите существующую папку `chapters`, в которой находятся эти же `.snbt`-файлы. Обычно это `config/ftbquests/quests/chapters` внутри папки сборки.
3. Сделайте резервную копию существующей папки `chapters`.
4. Скопируйте все файлы из папки `chapters` этого проекта в найденную папку, подтвердив замену одноимённых файлов. Саму папку сборки и файлы прогресса заданий удалять не нужно.
5. Запустите игру и откройте книгу квестов. Для многопользовательской игры замените файлы на сервере, который предоставляет игрокам квесты.

Используйте перевод с той версией сборки, из которой получен исходный архив. Эти файлы не устанавливают моды и не обновляют сборку.

## Сохранность квестов

Идентификаторы, зависимости, предметы, условия заданий, награды, координаты, ресурсы изображений и переходы между главами сохранены. Файлы записаны в UTF-8; расширения и имена файлов остались прежними.

Перевод выполнен с автоматической основой и редактурой основных игровых терминов. Названия модов, технические идентификаторы и названия музыкальных композиций сохранены для удобства поиска. Названия предметов и задач, автоматически подставляемые самим Minecraft или модом, используют язык соответствующего мода.

Надписи, встроенные в PNG-изображения, не изменены: сами изображения отсутствуют в предоставленном архиве. Исторические предупреждения об удалении модов переведены как часть исходного текста; они не являются сообщением о текущих планах авторов сборки.

## Проверка

`validation-report.json` содержит количество глав и заданий, число обработанных строк и контрольную сумму SHA-256 каждого переведённого файла. При сборке проверены синтаксис SNBT, сохранность всех нетекстовых данных, последовательность кодов оформления и адреса ссылок. Запуск внутри Minecraft не выполнялся.

## Состав

- `chapters/` — готовые переведённые главы.
- `validation-report.json` — результаты проверки и контрольные суммы.
- `README.md` — инструкция по установке.

Исходные квесты и материалы сборки принадлежат их авторам. Этот проект содержит перевод предоставленных файлов; отдельная лицензия на исходные материалы здесь не назначается.
